# PlankWin

Док для Windows 10/11 в духе Plank. Закреплённые программы и открытые окна в одной панели — с живыми превью, jump lists, избранным и тем, чему таскбар так и не научился.

**[Скачать последнюю версию](https://github.com/EugeneAlimov/PlankWin/releases/latest)** · [English](README.md)

## Возможности

- **Панель** у любого края экрана. Всегда видима, автоскрытие или умное скрытие. Плавная анимация, индикаторы запущенных программ, прокрутка, когда иконки не помещаются.
- **Несколько мониторов**: своя панель на каждом экране со своими настройками и только окнами этого экрана — как таскбар на каждом дисплее. Любую панель можно выключить из трея; горячие клавиши работают на панели под курсором.
- **Превью окон** при наведении: живые миниатюры, Aero Peek, закрытие окон, список или сетка.
- **Недавнее и задачи** в контекстном меню: jump lists любой программы (те же файлы, что на таскбаре), недавние документы Office, последние проекты TIA Portal, задачи вроде «Новое приватное окно». Пункты можно закреплять.
- **Избранное**: звезда для папок и отдельная кнопка для файлов. Добавление перетаскиванием, своё имя на панели без переименования файла, копирование и вставка из буфера обмена прямо в избранную папку.
- **Клавиатура и клики**: модификатор + 1…9 — N-я программа, модификатор + 0 — избранное. Shift-клик — новое окно, Ctrl+Shift-клик — от администратора, Alt-клик — папка программы.
- **Счётчики** непрочитанного из заголовков окон (Telegram, WhatsApp, почта…).
- **Оформление**: цвета, скругление, рамки, плоская панель или профиль «крыла».
- **Языки**: русский, English, українська, Deutsch.

## Установка

1. Скачайте `PlankWin-x.y.z-win-x64.exe` со страницы [Releases](https://github.com/EugeneAlimov/PlankWin/releases/latest).
2. Запустите. PlankWin предложит установиться в `%LocalAppData%\Programs\PlankWin` с ярлыком в Пуске. Права администратора не нужны. Можно отказаться и запускать откуда угодно.

SmartScreen может предупредить о неизвестном издателе (exe не подписан): **Подробнее → Выполнить в любом случае**.

**Удаление**: Параметры Windows → Приложения или значок в трее → «Удалить PlankWin…».

## Обновления

Вскоре после запуска и затем каждые 6 часов PlankWin проверяет новую версию на GitHub и предлагает обновиться из трея. Отключается в Настройках.

## Настройки и резервная копия

Настройки лежат в `%LocalAppData%\PlankWin`. «Настройки → Экспорт настроек…» сохраняет всё в один .zip, «Импорт настроек…» восстанавливает на другом ПК.

## Что-то сломалось?

После сбоя PlankWin при следующем запуске покажет отчёт. **Скопируйте** его и отправьте автору или откройте [Issue на GitHub](https://github.com/EugeneAlimov/PlankWin/issues) прямо из окна отчёта.

## Сборка из исходников

Нужен .NET 8 SDK на Windows.

```
dotnet publish PlankWin.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Пуш тега `vX.Y.Z` автоматически собирает релиз в GitHub Actions.
